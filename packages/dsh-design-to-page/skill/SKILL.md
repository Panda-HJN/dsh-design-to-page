# 设计稿还原（design-to-page）

**一句话**：JSON 定几何，PNG 定像素真值；浏览器当光栅器，diff 当裁判；整页定结构、裁剪定细节。

## 四条纪律

1. **几何信 JSON，视觉信 PNG**。必须回 PNG 核的四件事：容器 `fill`（可能根本没有，别补白底）、1px 描边（可能只在坐标里）、文本行高（导出 22.4 → 用 22）、文本大小写（导出可能是 `Example Department`，PNG 上可能是 `Example DEPARTMENT`）。可见性只信 PNG。
2. **整页定结构，裁剪定细节**。全页会被降采样，1px/8px 必糊；裁剪在原生 2x 上做，2–4x 放大看图标。每轮只裁 2–4 张"不确定处"，不要用裁剪图量整体定位。
3. **只写约束**。等宽兄弟 + ≥2 列 + 整除 → `grid`；单轴堆叠 + gap 全等 + 贴起点 → `flex`；只有 badge/装饰/刻意出血保留绝对定位。父级 1px 边框 → 子元素内边距减 1；行高用像素实测整数；图片先色块 + `data-slot="image"`；新颜色进 token。
4. **diff 定胜负**。原生 2x 比、双方不缩放、按单张图遮图片槽；顺序：先看位移 → `>40`（结构）→ `>10`（抗锯齿）；每次只改一处，重跑同一条命令。

## 工具顺序

```
design_ir        标注 JSON → IR（布局文法+置信+组件聚类+图片槽+不变量+遮罩）
design_measure   裁剪 / 取色 / 平均色 / 并排（原生 2x）
design_shot      CDP 截图（视口/DPR 精确，输出 [data-slot] 矩形）
design_diff      MAE / >10 / >40 / 位移 / 分区 / metrics.json / 门禁
```

## 流程

1. `design_ir` → 读 `report.md`：先看**布局指纹**里置信 ≥0.9 的 grid/flex（可照抄），再对齐 `invariants.json` 写 token。置信 <0.8 的节点裁剪核对。
2. 按 `layout.json` 写结构：只写约束（`grid-cols-4 gap-24`），不搬 `left/top`。卡片这类重复结构用 `instances.json` 直接驱动数据。
3. `design_shot --width=<画板宽> --height=<画板高> --dpr=<倍率>`；检查最终 URL 不是 `/login`、`phantomScrollbar=false`。
4. `design_diff --maskFile <shot.json>`；**位移不为 0 先查版心/视口/端口**，再追 `>40` 的分区。
5. `design_measure --pair` 看单块细节；`--crop` 放大图标；`--sample` 取 1px 边框色。
6. 达标后跑项目门禁：lint / type-check / build；还原是开发步骤，不写 e2e。

## 判定规则

| 现象 | 先查什么 |
|---|---|
| 整体位移 dx/dy 非 0 | 版心宽度、容器 margin、视口宽、DPR、滚动条 |
| `>40` 集中在文本 | 字号/行高/字重、文本大小写、字体族是否落地 |
| `>40` 集中在卡片边界 | 卡片高度、内边距、分割线、描边宽度 |
| 整片均匀 `>10` | 背景色/渐变、遮罩口径 |
| 只有图标区域 | 图标尺寸错位或未遮罩，先遮再判 |

## 常见陷阱

- 视觉顺序 ≠ JSON 顺序：导出子节点顺序是图层顺序，按 `(top,left)` 重排（`design_ir` 已做）。
- 父级边框补偿是**设计端**做的（子容器 121 vs 父 120），页面端不要再减，否则反向错 2px。
- 图片内容不在 JSON 里：只有 `basic.type == "image"` 标记；用平均色块占位并保留 `data-slot`。
- 装饰件只能给候选：背景插画/光斑不要当内容画，遮罩或单独出资产。
- 纯矢量零件（图标内部）判成 `absolute` 是对的，别给它们写布局文法。

## 完成标准

- 遮图片槽与装饰后：`>40 ≤ 4%`、`MAE ≤ 6`（**新项目必须重新标定**）、位移 0 或可解释；
- 报告写清：视口/DPR、遮罩口径、三项指标、位移、门禁、遗留清单。
