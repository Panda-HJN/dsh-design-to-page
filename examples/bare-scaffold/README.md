# Bare scaffold

An empty Vite + Vue 3 + TypeScript + Tailwind CSS 4 + Element Plus project.

It exists so you can try the `design_shot` / `design_diff` tools against a running dev server
without shipping anyone's design.

```bash
pnpm install
pnpm dev          # http://localhost:5173
```

Nothing here reflects a real product: no design files, no brand assets, no business copy.
